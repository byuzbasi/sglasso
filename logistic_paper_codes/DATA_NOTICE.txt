CoRSIVSZ - source attribution and distribution notice

This is a processed analysis panel from GSE84727 (development) and GSE80417
(independent test), using the published CoRSIV/ESS/SIV cluster annotation.
It is not a newly collected dataset or the original paper's 1,982-region panel.
Original data sources and creators must be credited when these data are reused.

Original publication:
Gunasekara CJ, Hannon E, MacKay H, et al. (2021).
A machine learning case-control classifier for schizophrenia based on DNA
methylation in blood. Translational Psychiatry 11, 412.
https://doi.org/10.1038/s41398-021-01496-3
